# Networking diagram

`phoenix-networking.drawio` is generated; edit `gen_diagram.py`, then:

```bash
python3 gen_diagram.py
/Applications/draw.io.app/Contents/MacOS/draw.io -x -f png -s 1 -b 20 -o phoenix-networking.png phoenix-networking.drawio
```

Icons in `icons/` are the same brand marks as `infrastructure/docs/architecture/icons/`.
